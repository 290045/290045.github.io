How to add more links: Adding a new link to your hub requires a simple two-step process: updating your index.html file to add the button, and adding the scrambled URL into your script.js file. [1] 
Here is exactly how to do it, using a new game or tool as an example.
------------------------------
## 🛠️ Step 1: Add the Button to index.html
Go to the tab section where you want the new button to appear (Games, Gateways, or Tools). Add a new <button> tag inside the <div class="grid-layout"> container. Give it a unique, safe data-id.
Example (Adding a new game):

<!-- Inside <div id="games"> ... <div class="grid-layout"> -->
<button data-id="app_minecraft">Application Module 24 (MC)</button>


* Stealth Tip: Keep the button name sounding academic (like "Application Module" or "Gateway Node") so passing eyes don't flag it.

------------------------------
## 🔒 Step 2: Encrypt and Add the Link to script.js

   1. Go to a site like [Base64Encode.org](https://www.base64encode.org/).
   2. Paste the raw URL you want to add (e.g., https://minecraft.net).
   3. Click Encode to get your scrambled string (e.g., aHR0cHM6Ly9jbGFzc2ljLm1pbmVjcmFmdC5uZXQ=).
   4. Open your script.js file and find the matching registry database object.
   5. Add your new data-id and paste the scrambled string right at the bottom of that list. [2] 

Example (Adding to the games registry):

const secureRegistry = {
  "app_rl2d": "aHR0cHM6Ly9za2VtcGlzdHkuZ2l0aHViLmlvL3JvY2tldF9sZWFndWVfMmQv",
  // ... your other existing game keys ...
  "app_rock": "aHR0cHM6Ly8yOTAwNDUuZ2l0aHViLmlvL3doYXQtYmVhdHMtcm9jay8=",
  
  // NEW LINK ADDED HERE (Remember the comma on the line above it!)
  "app_minecraft": "aHR0cHM6Ly9jbGFzc2ljLm1pbmVjcmFmdC5uZXQ="
};

------------------------------
## 📋 Where to Add Based on Tab Type

* For Games: Add the button inside <div id="games"> and add the encoded URL key inside the secureRegistry object in your JS file.
* For Gateways (Proxies): Add the button inside <div id="routing"> and add the encoded URL key inside the networkRegistry object in your JS file.
* For Tools: Add the button inside <div id="tools"> and add the encoded URL key inside the utilityRegistry object in your JS file.

Once you save both files and push your changes to GitHub, your robotic static.yml script will automatically deploy the site with your new links hidden away safely.
